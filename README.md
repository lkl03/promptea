# Promptea

Analyze your prompt, detect issues, and generate an optimized version tailored to each AI (GPT, Gemini, Claude, etc.) and your goal (text, study, code, data/JSON, image, marketing).

## Latest update — v1.1.6 (2026-07-09)

Three new SEO guides: DeepSeek prompts (code with constraints, JSON extraction, analytical reasoning), few-shot prompting (examples vs. instructions, classification and style templates), and prompt quality scoring (five-dimension self-evaluation framework, rapid debug templates). Minor improvement: Changelog page now has its own SEO metadata instead of inheriting the generic app title. Full details in [CHANGELOG.md](./CHANGELOG.md) and the weekly update PR.
